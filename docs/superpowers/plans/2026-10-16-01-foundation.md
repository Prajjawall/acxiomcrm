# Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans if your harness has them; otherwise execute task by task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A building, tested, containerised solution skeleton with the Domain/Application primitives every later plan relies on.

**Architecture:** Four src projects plus test projects per `docs/architecture/ARCHITECTURE.md` §1. Pure Domain rules, Application contracts, an EF/Identity `CrmDbContext` with an initial migration, a minimal Web host with logging, health checks and typed options, and a Testcontainers-backed test fixture.

**Tech Stack:** .NET 10, EF Core 10 (SQL Server), ASP.NET Core Identity, Serilog, xUnit, Shouldly, NSubstitute, Testcontainers.MsSql, Respawn, NetArchTest.Rules, Docker, GitHub Actions.

**Spec:** `docs/prd/PRD.md` (NFR-03, 04, 07, 08, 10; D-01..D-03, D-11, D-14, D-15, D-24, D-27, D-28), `docs/architecture/ARCHITECTURE.md`, `docs/architecture/SECURITY-AUTHZ.md` §1–2.

## Global Constraints
- SDK pinned by `global.json` to the .NET 10 SDK (`rollForward: latestFeature`).
- `Nullable` enabled, `TreatWarningsAsErrors` true, `AnalysisLevel` latest-recommended, `ImplicitUsings` enabled, `LangVersion` default for net10.0.
- Central package management; every `PackageReference` in a csproj has **no** `Version`.
- Project names and root namespaces: `AcxiomCrm.Domain|Application|Infrastructure|Web`; tests `AcxiomCrm.<X>.Tests`, `AcxiomCrm.E2E`, `AcxiomCrm.TestSupport`.
- Banned APIs (via `BannedSymbols.txt`): `DateTime.Now`, `DateTime.UtcNow`, `DateTime.Today`, `DateTimeOffset.Now/UtcNow`, `FromSqlRaw`, `ExecuteSqlRaw`, `Html.Raw` (allowed only in files listed in the exemptions file).
- Phone rule D-11: `^[6-9]\d{9}$` after normalisation. Business zone default `Asia/Kolkata`.
- Canonical messages: PRD §4 verbatim.
- No secrets in repo. Dev SQL password only in `docker-compose.yml` via `${ACX_DB_PASSWORD:?set in .env}`; `.env.example` has a placeholder.

## Review Focus
- Phone input forms: `+91 98765 43210`, `098765-43210`, `9876543210`, `98765 4321` (9 digits), `5876543210` (starts with 5), `９８７６５４３２１０` (full-width digits). Expected: first three normalise to `9876543210`; the rest are invalid, never throw.
- Email edge cases: leading/trailing spaces (trimmed), uppercase (normalised lower), `a@b` (invalid), `a@b.c` (invalid, TLD ≥ 2), 255-char email (invalid), `null`/empty (invalid, never throws).
- Business "today" near midnight: UTC 18:29 vs 18:30 on 2026-10-16 with `Asia/Kolkata` are 23:59 on the 16th and 00:00 on the 17th.
- Unknown time-zone id in config: app fails fast at startup with a clear message rather than silently using UTC.
- `PageQuery(Page: 0, PageSize: 10_000)`: clamps to page 1, size 100, never negative skip.
